# Sumi 1.1 demo — about ten minutes

Run `npm ci` then `npm run dev`; open the printed local URL. Use a disposable guest journal. No default account/password exists; demo users/databases are excluded.

1. Begin my journal; set study time/time zone. Show prerequisite-aware recommendations and introduced/practised/mastered definitions.
2. Open a kana lesson: explanation →worked example →guided exercises. Use both hints, intentionally miss, read specific feedback, deliberately skip. Assisted work never awards mastery.
3. Try independent recall, fresh targeted corrections and scheduled review. Navigation is not learning credit.
4. Quiz & Tests →Hiragana →Selected rows →Y only →Continuous Practice. Miss one of the 3 questions. All appear before the new round explains repetition and prioritizes mistakes without immediately repeating the last character. Options shuffle independently.
5. Reload before and after checking an answer. Exact question/options/selection/answers/score/round persist. Finish Practice; inspect summary/skips. Focus on these mistakes creates a separate filtered session.
6. Katakana →Dakuten →Test. Save an answer; correctness/score remain hidden through reload. Finish Test reveals them. Finite sessions shorten to tiny pools; continuous needs at least 2 eligible questions.
7. Reference →Kanji →search mountain →山. Show on/kun,3 strokes, words and supported sentence. Learn marks introduced. Bookmark, quiz the contextual word or open stroke practice. Try vocabulary/grammar and romaji/English search.
8. Writing: animate/hide a sourced model, draw and save for self-review. Type both basic scripts and kanji-word kana readings. There is no automatic handwriting/grammar quality score.
9. Show due review, mistakes/bookmarked quizzes and separate recognition/typed recall. Read original stories; try optional synthetic-device audio. Microphone recordings stay browser-only.
10. Settings: attach an account to guest progress, choose preferences and export private records. Show deletion controls without deleting audience data. Educator review, account recovery and live PostgreSQL staging remain launch work.

Unpublished local handover. Never demonstrate using real learner records, production credentials or a live production database.
